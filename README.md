# 🍽️ Foodiland

A modern recipe discovery and food inspiration platform built with a clean, responsive design. Foodiland helps users explore delicious recipes, discover cooking ideas, and enjoy a seamless browsing experience across all devices.

![Foodiland Banner](./public/preview.png)

## 🌐 Live Demo

**Website:** https://foodiland-kappa.vercel.app/

---

## 📖 Overview

Foodiland is a modern food and recipe web application designed to provide users with an engaging culinary experience. The platform showcases recipes, food categories, featured dishes, and cooking inspiration through an intuitive and visually appealing interface.

Whether you're looking for your next meal idea or simply exploring food content, Foodiland delivers a smooth and enjoyable user experience.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js (v18 or later)
* npm or yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/foodiland.git
```

Navigate to the project directory:

```bash
cd foodiland
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Run production build:

```bash
npm start
```
